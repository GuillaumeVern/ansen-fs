# Changelog

## v1.0.81 - 2026-07-22

### Security
- Le compte `admin` initial est désormais créé avec un mot de passe aléatoire (144 bits) au
  premier démarrage, au lieu d'un mot de passe par défaut fixe.

## v1.0.80 - 2026-07-22

### Fixed
- Correction de plusieurs problèmes d'accessibilité (RGAA) sur la page principale.

## v1.0.79 - 2026-07-22

### Changed
- Mise à jour de la configuration Jenkins (`tools`) pour inclure Node.js, nécessaire au build
  du frontend.

## v1.0.77 - 2026-05-20

### Added
- Suppression de fichiers et de dossiers depuis l'interface, avec confirmation avant suppression.

## v1.0.75 - 2026-05-16

### Added
- Téléchargement de fichiers.
### Fixed
- Fiabilisation de l'upload.

## v1.0.74 - 2026-05-08

### Added
- Intégration de NG-ZORRO comme bibliothèque de composants UI pour le frontend Angular.

## v1.0.73 - 2026-05-06

### Added

## v1.0.72 - 2026-05-03
